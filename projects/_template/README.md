# Episode template

Copy this directory to `projects/EP###-slug/` for a new episode.

- `script/`: script, outline and dialogue.
- `characters/`: character bible and approved reference images.
- `locations/`: world/location settings and approved references.
- `storyboard/`: JSON + human-readable shot board.
- `prompts/`: exact prompts and generation manifest.
- `references/`: images/videos supplied or approved for generation.
- `clips/`: generated raw clips, one folder per shot.
- `audio/`: voice, music and SFX stems.
- `subtitles/`: SRT/ASS.
- `final/`: exported MP4 only.
- `reports/`: continuity, media and final QC reports.
