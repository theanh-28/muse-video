# Muse Video Prompt — Six-part working template

> Adapt only after probing actual Muse capabilities. Do not assume every field is supported.

1. **Format and duration** — target aspect ratio, requested duration within verified limit, one continuous shot or defined transition.
2. **Subject and identity** — canonical character description and exact continuity locks; identify what attached reference images govern.
3. **Scene and environment** — location, time, weather, layout, fixed landmarks and props.
4. **Action over time** — one dominant action with clear chronological beats; specify start and end pose, direction, contact, reaction and motion completion.
5. **Camera and visual language** — shot size, angle, movement, lens/look, focus, lighting, palette and framing.
6. **Audio and constraints** — dialogue, ambience, SFX, music only when supported; negative constraints and no unwanted additions.

## Handoff clause for a continuation shot

Continue from the supplied previous-shot frame/snapshot. Treat it as the exact visual state at the beginning of this clip. Preserve the established character identity, costume, prop ownership, screen direction, location, lighting and camera geography. Continue the action from its current phase; do not replay the previous action. End in the specified handoff state.

This clause is not a guarantee. Use the provider's native continuation feature if actually available; otherwise use image reference or an edit transition.
